# Phase IV Glossary Addendum

**Docker Image**
A versioned, immutable runtime artifact.

**Minikube**
Local Kubernetes cluster used for evaluation.

**Ingress**
Single HTTP entry point routing traffic to services.

**Helm Chart**
Templated Kubernetes deployment package.

**Values.yaml**
Configuration file controlling Helm behavior.

**Proof Run**
Recorded execution showing system behavior via CLI.
